# User Preferences & Formatting Guidelines

- **No LaTeX / Math Markup**: Never use LaTeX notation or math blocks (e.g., `$`, `$$`, `\mathbf`, `\text`, `\arrow`, `\rightarrow`, `\times`, `\sigma`).
- **Clean Plain-Text Formatting**: Present all calculations, metrics, equations, and summaries using standard, clean Markdown and plain text (e.g., "Total: 5,722 lines across 46 Python files", "AUC = 0.865", "x -> y").
